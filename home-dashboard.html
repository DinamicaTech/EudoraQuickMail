Home dashboard

The fixed Home tab summarizes account health, backups, pending mail and local mail activity. Receiving and sending are tracked separately. Errors remain visible until a successful operation or connection test for that channel. Unknown or old results are not a guarantee that a server is available. This history begins with the first version supporting the dashboard; it does not infer past SMTP success from a stored password. Double-click an account to edit it or test its connection.

Backup information comes only from local receipts: opening Home never connects to the NAS or changes network credentials. An external backup window is not proof that the external backup succeeded. Backup settings and History open the corresponding backup-agent tab. Restore-test warnings offer a direct link to the Restore test settings.

The attention panel groups problems with an action beside each warning. Test checks one account; Test all checks active network accounts with progress and cancellation. Test sending on all accounts connects/authenticates without sending an email (Graph sending permissions cannot be verified this way). Check these accounts now downloads mail for accounts with no receive check recorded. These checks run only when explicitly requested, not when Home opens.

Activity counts use stored message dates, not download dates. Gmail label copies with the same Message-ID are grouped within each account. Drafts and scheduled messages are excluded from activity; pending unread also excludes Trash, Junk and RecoveryDeleted. Counts describe local data, so unsynchronized mail and messages with unknown direction may not be represented. The account selector scopes the statistics; the shortcut search buttons explicitly search all accounts; the unread shortcut excludes Trash, Junk and RecoveryDeleted to match the pending count. Changing the account selector reuses the loaded statistics without another database query. The daily comparison uses elapsed calendar days this week/month, including today. Folders to review lists local unread counts and drafts, with buttons to open those folders. Today’s events retain their calendar account colors and New appointment opens the existing event editor.

Google Calendar shows each configured Google calendar account, whether calendar sync is enabled, its last successful synchronization and any recorded failure. Sync now retries that account only, with progress and cancellation; it does not send or receive mail. Offline/Focus mode and ongoing maintenance block this action. Opening Home itself only reloads cached events. Calendar health starts being recorded with this feature; older successful synchronizations cannot be inferred from existing appointments. Today’s agenda includes all calendar sources regardless of the Calendar tab’s source filter, shows all-day events first, then timed events, and retains cached appointments with a warning when synchronization is unverified or stale. Double-click an appointment to use the same open/edit behavior as the calendar, including existing read-only restrictions and invitation handling.

In Settings → General, Show Home after 15 minutes of inactivity is enabled by default. It measures activity in QuickMail, waits while an editor/dialog/operation is open, and does not bring the application to the foreground. Your other tabs and list selection remain available. Home loads asynchronously and refreshes at most every five minutes while visible, unless you press Refresh. Statistics have a time limit and can be retried without blocking mail use.
