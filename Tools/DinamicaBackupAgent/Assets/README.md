# Backup application icon

Generated with the built-in image generation tool; transparent PNG source is retained.
ICO contains 32-bit PNG frames at 16, 24, 32, 48, 64, 128 and 256 pixels.
Convert-BackupIcon.ps1 performs format conversion and resampling without altering the design.
It refuses to overwrite an existing ICO.

Prompt: Use case: logo-brand. Create a single polished Windows desktop application icon
for a backup utility: a compact blue archive storage box with a lid and a bold green
circular recovery arrow prominently wrapping across its front. Charming but professional,
clean slightly dimensional vector-like illustration, strong silhouette, very few details,
thick shapes legible down to 16 pixels. Centered square composition filling 85% of the
canvas. True transparent background. No text, no letters, no watermark, no surrounding
tile, no shadow outside the icon. Blue box and green arrow clearly separated with a thin
light outline where they overlap.
