Reliability and diagnostics

If delivery succeeds but EQM cannot save the sent copy, the message stays in Scheduled as Sent — archival pending. It retries saving the copy without sending the email again. An already-sent message cannot be edited or replaced as an unsent scheduled message. Switching to Offline allows an active send to finish but stops subsequent queued sends.

Advanced searches run without blocking the interface. Long searches show Cancel search; cancellation keeps the previous results rather than substituting incomplete results. Help > Check for updates reports its result explicitly, including disabled checks and failures.

Damaged or unreadable accounts.json, rules.json or views.json is reported rather than silently replaced with an empty configuration. Close EQM and restore a known-good backup; the .previous sibling file contains the previous valid saved version when available. Do not assume that an older configuration includes your latest account/rule changes.

Each diagnostic log (quickmail.log, performance.log) keeps up to three rotated files (.1 newest through .3 oldest), in addition to the current file, with a 10 MiB limit per file for newly generated logs. Existing oversized logs rotate on the next write. When reporting an issue, include the relevant rotated files if the operation is no longer in the current log.
