Private Notes and message investigation

Search punctuation and wildcards

When an F3 search contains an unquoted * or ?, QuickMail asks how to interpret it: Yes enables wildcard matching (potentially a slow text scan; a single trailing * can use the prefix index), No searches literal text without wildcard expansion, and Cancel does not run the search. No is the default. Literal terms are stored in quotes in search history and saved views. You can also type quotes yourself, for example S:"Annual report?". The word index ignores punctuation: this finds the words, not necessarily the question-mark character. Attachment-name searches use literal filename matching instead of the word index. Searches run off the UI thread. If a search takes over two seconds, its progress window offers Cancel search; no percentage is shown because SQLite does not provide a reliable completion percentage.

Notes: beneath Subject in composition and the existing-message editor holds private keywords or annotations. It is stored locally and backed up with the database, never sent to recipients. The message list has a sortable Notes column. General search includes notes; use N:project to search only Notes. Bare N continues to mean unread messages. Private notes require the local store and are unavailable in online-only mode.

Before sending to more than three distinct visible TO/CC addresses across different domains, EQM offers to protect their addresses. Yes puts your own address in TO and moves the original TO/CC recipients to BCC, preserving existing BCC recipients and removing duplicates. No keeps them visible; Cancel returns without sending. Domain differences are a warning heuristic, not a determination that the people do not know one another.

To export correspondence, open Email History, select the desired messages (Ctrl+A selects the displayed list), then choose Export → Selection with attachments and index…. A new directory contains EML messages, native attachments and an index.html linking them. Only selected, loaded rows are exported. Missing content is reported as incomplete in the index; Notes are not exported.

Activity… in the message context menu shows recent local observations, rule actions, moves, snooze/wake events and acceptance of queued sends. Recording starts with this version; it cannot reconstruct older operations. Local catalogue additions/removals are not proof of server delivery or deletion. Events are retained up to 90 days and 100,000 events per profile, with the latest 500 shown per message. Gmail labels sharing a Message-ID share the activity history within the account. # Attachment investigation tools

Hover over an attachment for 750 ms to preview JPG/JPEG, PNG, GIF (first frame), BMP, PDF or TXT. This works in the reading pane and detached message windows. The floating preview does not select the attachment or take keyboard focus; right-click, double-click and drag remain available. Move onto the preview to scroll text or use Previous/Next page for PDFs. Move away or press Esc to close it. Clicking the attachment closes the preview before the normal attachment action. The preview opens beside the attachment label on the right, up to 900 × 1000 logical pixels, and shifts vertically to fit the monitor. Smaller screens use a reduced preview; the left side is used only when there is insufficient room on the right. Remote attachments require Download and preview; hovering never downloads them automatically. Previews are limited to 25 MB, text to 64K characters, and large images to 100 million source pixels. TXT preserves line breaks (UTF-8 and BOM-marked UTF-16/UTF-32); PDF pages are rendered by Windows, not a browser. Missing files show the original path. Disable Preview attachments on hover in Settings > General > display options if preferred (enabled by default).

Tools > Attachment explorer lists cached attachments in the current folder, or throughout EQM with Everywhere. Search filenames, senders or subjects; sort the columns; save selected files without overwriting existing names; or use Go to message. Embedded images and messages whose attachment metadata has not been downloaded are excluded. A capped result asks you to refine the search. The title counts displayed attachment rows. Sizes are shown in MB (1,048,576 bytes), with two decimal places and regional separators, right-aligned and sorted numerically. Search reads cached database metadata only; it does not scan directories. Directory scanning is a separate, explicit Locate missing attachment operation.

For a missing file, select Locate missing attachment, choose a backup directory and inspect the candidates. Recover a copy copies into EQM; Use candidate location changes only this reference. Both require confirmation. Name/size matches are not proof; a known SHA-256 must match. Backup files are never deleted. Reopen the message after repair.

Analyze rule conflicts in Tools or the message context menu examines the selected messages, listing active matching rules in execution order and flagging competing actions. Blocked later rules remain visible. This is a read-only simulation, not execution or a guarantee of remote delivery.
