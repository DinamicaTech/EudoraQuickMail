Private Notes and message investigation

Notes: beneath Subject in composition and the existing-message editor holds private keywords or annotations. It is stored locally and backed up with the database, never sent to recipients. The message list has a sortable Notes column. General search includes notes; use N:project to search only Notes. Bare N continues to mean unread messages. Private notes require the local store and are unavailable in online-only mode.

Before sending to more than three distinct visible TO/CC addresses across different domains, EQM offers to protect their addresses. Yes puts your own address in TO and moves the original TO/CC recipients to BCC, preserving existing BCC recipients and removing duplicates. No keeps them visible; Cancel returns without sending. Domain differences are a warning heuristic, not a determination that the people do not know one another.

To export correspondence, open Email History, select the desired messages (Ctrl+A selects the displayed list), then choose Export → Selection with attachments and index…. A new directory contains EML messages, native attachments and an index.html linking them. Only selected, loaded rows are exported. Missing content is reported as incomplete in the index; Notes are not exported.

Activity… in the message context menu shows recent local observations, rule actions, moves, snooze/wake events and acceptance of queued sends. Recording starts with this version; it cannot reconstruct older operations. Local catalogue additions/removals are not proof of server delivery or deletion. Events are retained up to 90 days and 100,000 events per profile, with the latest 500 shown per message. Gmail labels sharing a Message-ID share the activity history within the account. # Attachment investigation tools

Tools > Attachment explorer lists cached attachments in the current folder, or throughout EQM with Everywhere. Search filenames, senders or subjects; sort the columns; save selected files without overwriting existing names; or use Go to message. Embedded images and messages whose attachment metadata has not been downloaded are excluded. A capped result asks you to refine the search.

For a missing file, select Locate missing attachment, choose a backup directory and inspect the candidates. Recover a copy copies into EQM; Use candidate location changes only this reference. Both require confirmation. Name/size matches are not proof; a known SHA-256 must match. Backup files are never deleted. Reopen the message after repair.

Analyze rule conflicts in Tools or the message context menu examines the selected messages, listing active matching rules in execution order and flagging competing actions. Blocked later rules remain visible. This is a read-only simulation, not execution or a guarantee of remote delivery.

See Attachment investigation for scope, keyboard navigation and limitations.
